No brew. No port. jige finds and installs the right build for this machine.

A package manager for old Macs that Homebrew dropped support for —
Monterey and earlier, still covered.

$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/hoyacom/jige/main/install.sh)"

Works on a brand new Mac too — neither Homebrew nor MacPorts need to be installed first.

For Macs Homebrew left behind

Run brew doctor on an old macOS (Monterey, Big Sur, Catalina…) and you'll see warnings like "Your Mac OS is too old" — brew install can simply stop shipping bottles for it. Older Intel Macs, like a 2015 iMac, fall off the officially supported list the same way. jige reads Homebrew's and MacPorts' own public recipe data over plain HTTP — no Homebrew installation required — and installs the right build for your exact OS and architecture, even on a machine brew has already given up on.

jim and dogu

Just as Homebrew splits installs into formula (terminal tools) and cask (Dock-visible GUI apps), jige draws the same line with one OS-agnostic question.

"Does installing it put an icon in the Dock/launcher you double-click to open?"
jim
"load" — the whole bundle carried on the jige frame
A GUI app that gets a Dock/launcher icon.
Maps to Homebrew's cask
dogu
"tool" — what a porter carries and uses by hand
A command or library you use straight from the terminal.
Maps to Homebrew's formula

One search. One install.

One search covers Homebrew (Cask/Formula), MacPorts, the Mac App Store, and jige's own repository at once, tagged by source. All plain public HTTP APIs — no brew, port, or mas required just to search. App Store apps install by name, no numeric ID needed.

$ jige search hop
Name                         Kind       Source            Version   Description
hop                          jim        Homebrew          0.5.2     View and edit HWP documents
hopper-disassembler          jim        Homebrew          6.6.2     Reverse engineering tool...
hopenpgp-tools               dogu       Homebrew          0.26.1    Command-line tools for OpenPGP...

(Mac App Store is off by default — calling Apple's servers on every search
 would be wasteful for people who only use brew.)

$ jige search hop --mas
Hop - Endless Arcade Hopper  jim        Mac App Store     1.6       Limitless LLC

$ jige install "Asphalt Legends" --mas
Recipe: Asphalt Legends (Mac App Store, listed version 53.5.3)
Running mas install 1491129197...
Done: Asphalt Legends (Mac App Store, id 1491129197, version 53.5.3)

Why this exists

Across several Macs (Apple Silicon, Intel+Homebrew, Intel+MacPorts), I didn't want to force Homebrew onto all of them. Homebrew-Cask already publishes a clean, community-maintained JSON API describing exactly what file and checksum each OS/architecture needs — jige just reads that over HTTP, no brew binary required. Wrap what already exists (Homebrew-Cask, MacPorts) and only add to our own repo what's in neither.
