지게 jige

brewもportも要らない — この機種に合うアプリを探してインストール

Homebrewがサポートを打ち切った古いMacのためのパッケージマネージャー
Monterey以前もそのままカバーします。

$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/hoyacom/jige/main/install.sh)"

新品のMacでも大丈夫 — HomebrewもMacPortsも事前インストール不要です。

Homebrewが見捨てたMacのために

古いmacOS(Monterey、Big Sur、Catalinaなど)でbrew doctorを実行すると "Your Mac OS is too old" といった警告が出て、brew installがbottleの配布を 止めてしまうことがあります。Apple Siliconではない古いIntel Mac(2015年製iMacなど)も、 公式サポート対象から外れてしまうのは同じです。jigeはそんな機種でも——Homebrewを インストールしなくても——Homebrew・MacPortsが公開しているレシピをそのまま読んで、 このマシンのOS・アーキテクチャに合うビルドを見つけてインストールします。

jim と dogu

Homebrewがインストール対象をformula(ターミナル用)と cask(Dockに表示されるGUIアプリ)に分けるように、jigeもOSを問わない 一つの質問で同じ線引きをします。

「インストールするとDock・ランチャーにアイコンが出て、ダブルクリックで開く独立したアプリか?」
jim
「荷物」— チゲに丸ごと載せる荷物
Dock・ランチャーにアイコンが出るGUIアプリ。
対応: Homebrewのcask
dogu
「道具」— チゲを担ぐ人が手に持ってすぐ使う道具
ターミナルで直接使うコマンド・ライブラリ。
対応: Homebrewのformula

一度の検索、一度のインストール

Homebrew(Cask/Formula)・MacPorts・Mac App Store・独自リポジトリを 同時に検索し、どこの出典かも表示します。すべて公開HTTP APIなので、このマシンに brew・port・masが一切無くても検索できます。Mac App Storeのアプリも数字のIDを 知らなくても名前のままインストールできます。

$ jige search hop
名前                         種類       分類              バージョン  説明
hop                          jim        Homebrew          0.5.2     View and edit HWP documents
hopper-disassembler          jim        Homebrew          6.6.2     Reverse engineering tool...
hopenpgp-tools               dogu       Homebrew          0.26.1    Command-line tools for OpenPGP...

(Mac App Storeは既定でオフ — brewしか使わない人にとって毎回
 Appleのサーバーを呼ぶのは無駄なため)

$ jige search hop --mas
Hop - Endless Arcade Hopper  jim        Mac App Store     1.6       Limitless LLC

$ jige install "アスファルト:レジェンド" --mas
レシピ: アスファルト:レジェンド (Mac App Store, 登録バージョン 53.5.3)
mas install 1491129197 を実行中...
完了: アスファルト:レジェンド (Mac App Store, id 1491129197, バージョン 53.5.3)

コマンド

brewとportどちらの名前にも合わせてあるので、どちらの指の記憶でも通じます。

jigebrewport
jige search <検索語>brew searchport search
jige install <名前>brew installport install
jige info <名前>brew infoport info
jige upgrade [名前]brew upgradeport upgrade
jige listbrew listport installed
jige config mas on|off——
jige uninstall <名前>brew uninstallport uninstall

作った理由

複数のMac(Apple Silicon、Intel+Homebrew、Intel+MacPorts)を使っていて、 全部にHomebrewを強制したくありませんでした。Homebrew-Caskはすでに、 どのOS・アーキテクチャにどのファイルをどのチェックサムで取得すべきかを きれいなJSON APIとして公開し、コミュニティが常に最新に保ってくれています。 jigeはそのJSONをHTTPで読むだけで、brewのバイナリは不要です—— 既にあるもの(Homebrew-Cask、MacPorts)はそのままラップし、 どちらにも無いものだけ独自リポジトリに追加します。
